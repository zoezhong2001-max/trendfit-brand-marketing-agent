# v0.4.0 Slice A · 品牌资产底层合同交付

状态：已实现，未发布。当前正式版本仍为 v0.3.1；品牌资产页面、文件上传和在线选品尚未接入。

## 本轮完成

- 新增可执行的泛商品合同：实体商品、餐饮菜单项、服务、数字商品和线下体验共用 `CatalogItem`；
- 将业务生命周期与营销可用性分离；
- 新增 Brand、CatalogItem、Variant、Availability、Claim、EvidenceRef、OnboardingBatch 与 BrandAssetSnapshot 的关联校验；
- 根据市场可用性、有效期、履约能力、事实审阅、Claim 与 hard blocker 确定性计算营销可用性；
- 新增不可变 BrandAssetSnapshot 与内容哈希，锁定一次评审读取的资产版本；
- 新增 Petlibro、奈雪和 BreezeCare 三个跨品类合成验收样本；
- 新增 Python 与浏览器侧合同和测试。

## 关键产品规则

1. 海外可售不能证明中国可售；
2. `retired` 或超过有效期的商品只能保留历史引用，不能进入新 Brief；
3. 服务商品缺少服务区域或已确认履约能力时不能成为 `eligible`；
4. Claim 不能跨品牌引用，也必须声明适用商品；
5. Snapshot 必须精确覆盖品牌当前商品与 Claim 版本，版本或哈希变化均拒绝加载；
6. 代码只校验数据关系，不证明合成事实为真，也不授权发布或投放。
